Shopping Copilot — TechJam 2026, Track 4 (AI Conversational Search)

A multi-turn shopping agent that finds one hidden product in a frozen
50,000-item Amazon catalog within ten turns. Scores 0.9746 on the official
evaluator against a 0.1067 baseline — running on the Python standard library
alone, with zero tokens, no network and no API key.

The second half of the video is about whether that number means anything. The
official evaluator's "customer" is a deterministic program that quotes the
target product's own description, so I built a second benchmark where the
customer is a language model told never to quote the listing. The same agent
scores 0.9746 against the first and 0.348 against the second.
